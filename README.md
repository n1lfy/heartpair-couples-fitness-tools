# Heartpair free tools

Free browser tools for couples who work out together: fitness bet generator, weekly workout planner, steps goal calculator and long-distance time zone planner.

These are the open-source versions of the free tools on [heartpair.app](https://heartpair.app/). Each tool is one self-contained HTML file: no build step, no tracking, no network requests.

### [Couples fitness bet generator](https://heartpair.app/tools/couples-fitness-bet-generator/)
Get a fun stake for your next workout bet: dinners, chores, massages and more. Free, no sign-up.

- Use it online: https://heartpair.app/tools/couples-fitness-bet-generator/
- Source: [`couples-fitness-bet-generator/index.html`](couples-fitness-bet-generator/index.html), a single HTML file with no dependencies

### [Couples weekly workout planner](https://heartpair.app/tools/couples-weekly-workout-planner/)
Plan which days you each train this week and see the days you can work out together.

- Use it online: https://heartpair.app/tools/couples-weekly-workout-planner/
- Source: [`couples-weekly-workout-planner/index.html`](couples-weekly-workout-planner/index.html), a single HTML file with no dependencies

### [Couples steps goal calculator](https://heartpair.app/tools/couples-steps-goal-calculator/)
Turn your daily steps into a fair combined goal for you and your partner.

- Use it online: https://heartpair.app/tools/couples-steps-goal-calculator/
- Source: [`couples-steps-goal-calculator/index.html`](couples-steps-goal-calculator/index.html), a single HTML file with no dependencies

### [Long-distance time zone planner](https://heartpair.app/tools/long-distance-time-zone-planner/)
Find the hours when you and your long-distance partner are both awake, to train together on a call. Free, runs in your browser.

- Use it online: https://heartpair.app/tools/long-distance-time-zone-planner/
- Source: [`long-distance-time-zone-planner/index.html`](long-distance-time-zone-planner/index.html), a single HTML file with no dependencies

## Embed a tool on your site
Every tool has an embeddable version. Open the tool on heartpair.app and copy the embed code at the bottom of the page.
